A responsive front-end student project built with HTML, CSS and vanilla JavaScript.

## Live demo
https://dashing-vacherin-fa6b0b.netlify.app

## Features
- Responsive layout for desktop and mobile
- Complaint form with validation and generated reference IDs
- Dashboard summary cards
- Search and category/status filters
- Status updates and delete confirmation
- Demo data loader and CSV export
- Browser-local persistence with localStorage

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Limitations
This is an educational front-end prototype, not an official municipal service. It has no server database, authentication, or municipal integration. Data stays in the current browser and is not shared across devices.

## Technologies
HTML5, CSS3, Vanilla JavaScript, localStorage.
