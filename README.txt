CivicConnect — Smart City Complaint Portal
===========================================

Run locally
1. Extract this folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. No installation, server, or internet connection is required for the basic demo.

Features
- Responsive dashboard and complaint form
- Required-field validation
- Reference ID generation
- Search and status/category filters
- Status update and delete confirmation
- CSV export
- Demo data loader
- Local browser storage using localStorage

Important limitations
- This is a front-end student prototype. It has no server, database, login, or municipal integration.
- Data is stored in the current browser only. Clearing browser storage may remove it.
- For public submission, upload index.html to a static hosting provider and test the deployed URL.
